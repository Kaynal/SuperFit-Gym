# SuperFit Gym — адаптивний вебсайт фітнес-клубу

## Опис проєкту
Цей проєкт є адаптивною лендінг-сторінкою фітнес-клубу **SuperFit**.  
Сайт створено як тестове завдання для демонстрації навичок верстки.

## Мета
Розробити сучасний, адаптивний та семантично правильний вебсайт спортивної тематики.

## Використані технології
- HTML5
- CSS3
- Flexbox
- Grid
- Media Queries

## Адаптивність
Сайт коректно відображається на:
- десктопах
- планшетах
- мобільних пристроях

## Особливості
- семантична HTML-структура
- адаптивна верстка
- оптимізовані зображення
- lazy-loading для зображень
- підключена Google Maps
